A 100-word villain monologue: a dark lord three centuries into the job receives the hero who came to end him — and tries to hand over the crown instead, provided the hero signs the paperwork first. The weariness lives in the pauses and deflections, never in a plain announcement of it.

## Run it

```sh
python3 main.py
```

This prints the monologue and writes it to `/output/entry.txt`.
